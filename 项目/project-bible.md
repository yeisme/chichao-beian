# 《赤潮北岸》项目圣经

## 项目定位

- 项目名：《赤潮北岸》
- 暂定发布书名：《赤潮末世：我把异兽做成科技树》
- 备选书名：《赤潮末世：从猎杀第一头潮兽开始》
- 类型：男频末世进化 / 异兽狩猎 / 战队群像 / 基地制造 / 城市战争
- 平台表达：低门槛打怪升级在前，工业重建与领袖成长在后。
- 年代：2080 年夏末开篇。
- 主角：叶知衡，16 岁，江湾高中贫困特招生，有打架传闻和长期独自解决问题的习惯。

## 一句话故事

> 赤潮降临后，十六岁的叶知衡发现自己能够把不同潮兽的适应特征稳定编译进身体；他从校园第一场近身猎杀起步，每杀死一头高阶潮兽，就让自己、队伍和北岸工业共同升级，最终从只会冲在最前面的独狼，成长为能让猎团、军队、工厂与普通人共同赢得战争的城市领袖。

## 读者核心问题

1. 叶知衡下一次会猎杀什么潮兽，获得什么能力？
2. 新能力将如何与旧能力组合，而不是简单数值变强？
3. 潮兽尸体会被制造成什么装备或公共技术？
4. 这次任务里哪名队友不可替代，队伍关系会怎样变化？
5. 一个只相信拳头的少年，什么时候真正学会带人、承担错误和放权？
6. 当个人进化可能导致赤化，他还能否保住人类身份？

## 世界前提

2080 年的人类社会高度依赖自动交通、分布式能源、身份鉴权、气候适应设施和区域供应链。赤潮沉降叠加异常台风与全球多点灾害，使传感器、通信、交通和关键设施协同失效；国家仍在，但救援能力被全国性灾情、污染隔离和运输中断严重削弱。

赤潮中的自组织介质能够记录并放大生物适应结构。微生物、昆虫、鱼类、鼠群和其他高代谢生物最先异变；随后不同城区形成具有环境特征的潮兽生态与巢区。

人类获得力量有三条主要道路：固定谱系的自然适应、依靠工业与医疗的殖装、以快速强大换取非人化的赤化。叶知衡是罕见广谱适应者，但每一阶只能固化一种能力，专精不如队友，跨谱系还会增加失控风险。

详细规则见 [赤潮变异、潮兽进化与工业跃迁](../设定/变异/赤潮变异与技术跃迁.md)。

## 核心故事发动机

```text
城市出现资源或生存危机
→ 危机指向一种潮兽与巢区
→ 小队侦察、训练与准备
→ 原计划失败，人物矛盾暴露
→ 团队协作完成猎杀
→ 叶知衡获得个人进化
→ 科研与工厂转译潮兽能力
→ 新装备和生产线改变城市规模
→ 更强生态或敌对势力到来
```

每次大猎杀必须同时兑现：个人升级、队伍升级、城市升级。详细门禁见 [核心爽点、升级与领袖成长引擎](core-payoff-engine.md)。

## 叶知衡人物核心

### 起点

- 会打、敢冲、抗压强、记仇，也具体报恩。
- 习惯先行动再解释，认为自己承担危险就不欠别人。
- 不信任组织，觉得讨论和等待只会错失机会。
- 面对弱者有保护欲，却容易把保护变成替别人决定。

### 内在缺陷

> 他把“我来承担”误认为领导，把“我能解决”误认为别人不必参与。

这让他前期能制造个人英雄场面，也必然造成队友跟不上、信息断裂、伤势隐瞒和错误决策。

### 成长终点

- 知道自己不是每个领域最强的人。
- 能把目标、风险、分工和撤退条件说清楚。
- 判断错误时公开复盘，不用下一场胜利掩盖代价。
- 愿意让队友完成关键击杀，让普通殖装部队成为战争主体。
- 建立自己失控、失联或死亡后仍能运行的指挥体系。

## 群像原则

- 前 50 章只稳定经营一支五人核心猎潮小队，不同时铺开十几个主视角。
- 队伍需要前排、感知/远程、医疗研究、工程装备和主角的广谱破局；每个位置都有主角无法替代的专业能力。
- 至少两名核心角色长期保持普通人或殖装路线，证明非觉醒者也能影响战争。
- 每卷由一名核心配角完成不可替代的重大选择；主角不能独占全部高光。
- 群像通过共同任务、战损、分配和战术冲突成长，不靠独立番外堆履历。

## 六卷主线

1. **红雨校园**：首杀、首次感应、五人小队雏形；主角从独自开路变成可靠队员。
2. **雷巢工业园**：夺回供电与制造节点；主角第一次带队，也第一次因错误判断付出代价。
3. **铁甲地铁**：打通交通与工业走廊；主角建立猎团并学会让队友完成胜利。
4. **空巢围城**：面对飞兽群和多战场危机；主角从猎团队长成长为联合作战指挥者。
5. **近海战争**：灾兽、敌对城市与工业走廊战争并发；主角必须在亲自猎杀和维持全局之间选择。
6. **母巢决战**：区域生态与人类文明正面对撞；主角建立不依赖个人永生和绝对控制的联盟体系。

## 必须保留的既有元素

- 第一章红雨、校园停电、内涝、侧门开路和右臂灼纹保留，作为灾变与首次适应入口。
- 药箱缺失保留，用于第二章制造资源冲突，并在潮兽袭击中检验人物选择。
- 母亲谢敏、弟弟叶知远和回家目标保留，为主角早期战斗提供私人动机。
- 沈照雪与叶知衡的互补保留：她重视清点、判断和撤退条件，他擅长近身行动与临场破局。
- 林栀、周焰、顾岚、程砚、陈野、许闻澈等现有角色保留，但其长期功能逐步转向猎潮、医疗、殖装、制造和城市战争。
- 国家救援困难、区域设施和 2080 年技术基线保留，作为大规模战争与工业复苏的现实底座。

## 降级为副线的旧内容

- 路线授权、配给、登记、征用和城市规则不再承担主爽点，只在资源分配、军队组织和领袖成长需要时出现。
- 父亲资产旧案保留为中后期工业资源与私人动机副线，不抢前期打怪升级节奏。
- 新秩序不靠会议辩论建立，而从猎物分配、装备使用、普通人参战、失控者处置和战时决策中自然显现。

## 最终主题

> 最弱的时候，叶知衡认为强大就是没人能再伤害自己；真正成为领袖以后，他才明白，强大是让许多原本无力的人也获得战斗、生产、选择和活下去的能力。
