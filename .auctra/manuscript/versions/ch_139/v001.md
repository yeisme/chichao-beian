# 第 2 章《同步静默与窄道屏障》

体育馆器材室改成的临时医疗仓里，空气湿冷而潮闷。

墙上的日光灯隔几秒抽搐一下，蓝白色的光斑投在积水的塑胶地板上。门外传来避难学生嗡嗡的议论声，门内则是纸盒拆开的沙沙声。

“急救箱里的冷藏袋不见了。”

沈照雪站在两排防潮铁架中间，拿着防水记录板清点，“进门登记时还有两盒冷藏止血血清和胰岛素，刚才清点，里面的保温包空了。”

帮忙抬伤员的体育生面面相觑。

“不能吧？刚才进来时大家都搜过外衣，谁能拿走那么大个保温包？”张磊擦着额头上的汗。

倒在门框边的许闻澈脸色发白，小腿上绑着布条，伤口边缘泛着淡红色的水肿。他忍着痛开口：“那保温包里有华锐的专供止血素。包装带着机械防盗扣，防盗扣要是破了会漏出葡萄糖味……东西恐怕是被什么划着拖走了。”

罗启明刚巡视完看台回来，一身湿透的衣服散发着雨水的腥味。他按着太阳穴叹气：“许同学，先别张扬，大家都在等药，要是传出去药少了——”

话没说完，站在门口的叶知衡突然抬手按住了门框。

“等一下。”叶知衡低声说了句。

罗启明皱眉：“叶知衡，正清点物资呢，你——”

“水沟里的声音停了。”叶知衡打断他，眼神看向地上的排水盖板。

他右臂皮下的刺痛从刚才开始就没停过。进入体育馆这十分钟里，他耳边一直混着各种杂音：屋顶的雨声、看台上的哭喊，以及脚下水沟里老鼠爪子抓挠铁管的细碎声音。

可就在刚才那一秒。

水沟里的抓挠声和滑水声突然全消失了。

隔着三十厘米厚的混凝土板，地下暗渠里那上百个细碎的移动点，在同一瞬间收住了动静。周围陷入一种异样的死寂。

这种毫无征兆的集体静默，分明是兽群扑食前收拢爪牙的征兆。

叶知衡来不及多说，一步跨到仓库门前，单手抓住重型镀锌铁滑门，用力往里一拉。

咣当！

滑门在轨道上划出刺耳的声响，原本两米宽的门洞顿时间被关得只剩下一尺来宽。

“你干什么！”张磊吃了一惊，“外面还有伤员要抬进来！”

“把旁边的球车推过来压住！”叶知衡头也没回，顺手扯过墙角的不锈钢排球车，推倒在门缝外侧，用粗铁架和几十个排球把剩下的窄缝卡紧。

罗启明正要上前拉开他：“叶知衡，你乱动器材——”

“听他的。”沈照雪按住了罗启明，指着叶知衡一直在发抖的右手。

沈照雪反应极快，转身抓起架子上的两块厚海绵垫：“张磊，拿垫子去死死顶住球车！”

几乎在海绵垫贴上球车骨架的下一秒。

砰！

地上的排水盖板被一股猛力直接顶飞，带着混有红油膜的水花溅了一地。几只猫般大小、眼膜充血发红的变异鼠从水沟里窜了出来，顺着墙角直冲仓库里的药物气味扑过来！

“啊！”室内两个帮忙的学生吓得尖叫。

但这群变异鼠刚冲出来，就被机械滑门和球车卡在了狭窄的通道里。最外面的两只砸在海绵垫上，后面的老鼠源源不断挤上来，顿时在窄缝口卡成一团。

“关滑门！”叶知衡喊道。

罗启明回过神来，浑身冷汗暴起，按住滑门把手拼命往死里一推。

咔嚓！

厚重的镀锌门重重撞合，门缝里夹住的几只变异鼠当场被铁门切断，血水顺着积水渗开。

门外看台上原本要发作的骚乱，在铁门的轰鸣声中陡然压了下来。

隔着门上的观察网，看台上的学生看得清清楚楚——涌出来的怪老鼠被死死卡在门外，防线没破。

“守住了……真卡住了！”张磊死死按着垫子，手心里全是汗。

但叶知衡脸上的表情没有松开。

右臂皮下的热意顺着血管向上蔓延，在他耳边的震动视图里，水下的移动发生了转向。

“还没完，它们走底下第二缺口。”叶知衡警惕道。

地上的鼠群受阻后，顺着货架底部的排水凹槽往里钻，直奔仓库内侧一条只有十多厘米高的地缝。一条背上鼓起肉瘤的大鼠从地缝里冒出半个头，一口咬住铁架最下层的保温包。

“小心！”罗启明喊道。

许闻澈离得最近，腿伤未愈，根本来不及避开。

叶知衡脚下一滑，顺着湿滑的地面跨到地缝前，手中的铝合金杆顺着排栅空隙猛地戳了下去！

噗嗤！

杆尖精准刺中地缝里的大鼠，将它死死按在水泥地面上。

看台上和仓库里的学生看在眼里——叶知衡在看不见水下情况的情况下，抢先一步把探头的怪鼠钉在地缝口，保住了伤员和通道。

沈照雪立刻把两卷重电缆推过来，死死砸在地缝上。

但那条变异大鼠极其顽劣，硬生生咬断了后腿，叼着装有冷藏止血素的保温内袋，滑回了深水暗道里。

帮忙封口的体育生陶俊因为动作慢了半拍，手臂被滑过的小鼠划出了一道血口。

仓库里重新安静下来。

空气里弥漫着怪鼠的血腥味和湿水味。

滑门守住了，大部分基础物资保了下来，但冷藏止血包被拖走了，陶俊也受了划伤。

叶知衡拔出铝合金杆，右臂有些脱力。他依然没有解释自己怎么判断水下位置的，在老城区摸爬滚打惯了的他，习惯用行动代替废话。

沈照雪走过来，递给叶知衡一块擦布：“保温包在没有电源的情况下，在常温里最多放三十分钟。”

罗启明看着地上的血迹，又看了看拿着金属杆喘气的叶知衡。

这位平时严厉的教导主任抹掉脸上的冷汗，第一次走上前，低声问叶知衡：

“叶知衡，下一波……会从哪来？”

叶知衡看向仓库深处通往地下设备层的防火门。

在他右臂的异样感知里，除了逐渐远去的小鼠震动，设备层最底下的泵房方向，正传来一声沉重而缓慢的跳动。

当。

当。

就像地下暗渠里有什么庞然大物在呼吸。
