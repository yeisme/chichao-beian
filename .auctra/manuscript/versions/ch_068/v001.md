# 第 1 章《红相降临：沉降纪元第一夜》

2080年夏末，晚自习过半。

黑板右上角的自适应环境屏突然闪烁起暗红色的故障光斑。

还没等台上的老师开口，一道刺眼的猩红光浪顺着玻璃窗轰然扫过，将整间教室照得犹如浸在黏稠的血泊中。紧接着，走廊尽头传来一声沉闷的电子死切声，顶灯在滋滋的电流剧响中熄灭，漆黑瞬间压了下来。

啪！

第一只鸟砸在双层防爆玻璃上。

不是羽毛散落，而是整只躯体如湿透的血肉弹丸般爆裂开来。暗红色的腥血顺着玻璃蜿蜒滑落，瞬间涂满整扇窗户。

紧接着是第二只、第三只——成百上千只羽毛硬化如铁刺的变异黑雀，带着尖锐的空气撕裂声，疯狂地撞击着实验楼的防暴外墙！

“啊——！血！全是血！”靠窗的女生尖叫着向后摔倒。

讲台旁，那盆绿萝的土壤里竟渗出蛛网般的暗红水渍。露在土外的细根在红水浸润下，如同被赋予了神经呼吸，竟绷紧、扭动着爬向课桌边缘，散发出一种带腥味的刺鼻异香。

教室内爆发出歇斯底里的骚乱。有人疯狂拍打门锁，有人将手机高高举向窗户，但手腕上的智能终端界面全部凝固在惨灰色的“网格断离”警告上。

坐在最后一排的叶知衡，双眼在暗红色的余光中冰冷如铁。

他没有尖叫，也没有盲目随人群向后挤。

他静静地伸手摸向课桌侧面，将一卷高强度胶带抽了出来，动作利落地缠紧了袖口与裤脚，防止湿水附着。接着，他反手按住了课桌旁那根重型铝合金器材杆。

在南江一中这所由豪门资源与资本子弟堆砌的精英学校里，叶知衡是个游离在边缘的异类。他来自老城区的破败巷弄，靠着全满分的竞赛成绩与扶贫名额才挤进这间教室。平时他穿着洗到发白旧校服，沉默、贫穷、独来独往。那些平日里众星捧月的权贵子弟看他的眼神，始终带着一种居高临下的厌恶与漠视。

但此时此刻，当灾难剥离了所有社会身份，那些平日里高高在上的娇生惯养者正吓得瑟瑟发抖，唯有叶知衡眼里只有猎人般的冷静。

“一楼进水了。”

第二排的沈照雪打开备用手电，将一道雪亮的光束打向前门缝隙。暗红色的水流正顺着门缝泛起油污般的膜状物，混着蓝白色的高压漏电火花，如毒蛇般蜿蜒进来。

“主楼梯已经发生踩踏！隔壁班几个学生被堵在下面了！”前门被撞开，两名裤脚沾满血水的学生哭喊着摔进室内。

班主任罗启明手里的扩音器吐出刺耳杂音，整栋楼的防爆声光系统彻底失控。

“罗老师，主楼梯不能走。”叶知衡霍然站起，声音在恐慌的噪杂中如重铁落地，“走东侧消防斜坡连廊。那边地势高，有手动防爆阀，不容易积水。”

沈照雪闻言抬头，手电光瞬间照在叶知衡脸上。她看到了少年眼底那股毫无波澜的冷冽，果断应声道：“听叶知衡的！体育生拿器材开路，女生在中间，手拉手不要散开！”

人群在恐惧驱使下慌乱涌向斜坡连廊。

就在整支队伍挤过侧门狭缝的瞬间，后方积水里突然爆开一声凄厉的惨叫！

许闻澈摔在了暗红色的水洼里。

作为华锐医疗董事长的独子，这位平日里前呼后拥的豪门少爷，此时小腿被断裂的金属栅栏撕开一道深可见骨的创口，血水瞬间染红了水面。周围积水里的红色油膜迅速贴附上去，伤口边缘以肉眼可见的速度浮现出怪异的发红肿胀。

更绝望的是，黑水阴影中骤然亮起三对通红的眼珠！

三只体型堪比中型犬、背部鼓起瘤状骨节的变异流浪猫，正从废墟阴影里贴地潜行，尖锐的獠牙间挂着腥臭的黏液，带着腥风直扑许闻澈的喉咙！

“别管我……救我！我爸是华锐董事长！谁救我我给谁一百万！”许闻澈摔在血水里，恐惧得歇斯底里地哭喊。

但在死神面前，钱财毫无意义。周围原本簇拥在他身边的同伴，吓得尖叫着连滚带爬逃开。

眼看变异猫锋利的爪子即将撕碎许闻澈的颈动脉——

轰！

一道惊雷般的破空声在狭窄的连廊里骤然炸响！

叶知衡踏水横空杀到！

他甚至没有一句废话，手中的铝合金器材杆在空中划过一道冰冷的半月，杆尖裹挟着全身的爆发力，噗嗤一声如热刀切黄油，精准无比地顺着领头变异猫的口器爆刺而入，直贯后脑！

嘭！重达数十斤的变异猫躯被这股蛮力硬生生钉死在混凝土墙壁上，黑血暴溅！

叶知衡顺势跨前一步，左手如鹰爪般死死拽住许闻澈的后领，将他像提麻袋一样从积水里单手拔起，右脚借着回旋之力，一脚重重蹬在第二只扑上来的变异体胸腔上！

骨裂声炸响！第二只变异猫如炮弹般飞倒出去，砸落水里激起滔天水花。

“闭嘴，把嘴闭上省点力气走。”叶知衡甚至没有看许闻澈一眼，甩干铝合金杆上的黑血，拖着死里逃生的许闻澈继续向体育馆推进。

许闻澈瘫倒在叶知衡脚边，浑身剧烈发抖。他看着眼前这个平时连看都懒得看一眼的贫困生，眼里第一次充满了无法言喻的震撼与恐惧。

嘭！

重型机械防火门在罗启明与几名体育生的合力下轰然关上，将漫天红雨与黑水里怪异的厮杀声隔绝在门外。

体育馆内聚集了上百名避难的学生与教职工，哭喊、祈祷与破防的骂声混成一片。

叶知衡靠在体育馆冰冷的钢构墙角，胸口剧烈起伏。

就在他强行压下喘息的瞬间——

咔！

一道极度剧烈的灼痛突然从他的右臂小臂上爆开！

叶知衡咬紧牙关撕开袖管，只见右臂皮下不知何时浮现出一道如火焰又如水流般发光的淡红色纹路。那纹路沿着血管疯狂延伸，仿佛有某种古老的生命在他的骨骼深处苏醒，散发出沉重的炽热共鸣。

随着灼纹的发烫，叶知衡耳边的声音发生了极其诡异的蜕变：

他不仅能听到体育馆顶棚红雨的狂暴轰鸣，更能极其清晰地“看”到脚下地下设备层暗渠里那些游动的复杂振动。

数十个细碎的爪击声、水流在管网里的异常分配，以及设备层最底端、被地下水淹没的泵房深处——

那声犹如深海巨兽在黑暗中张开肺叶般，沉重、缓慢、带有一阵阵水流搏动的**低频心跳**。

咚。

咚。

沈照雪怀抱记事本快步走来，白皙的脸上毫无血色：“叶知衡，不好了。急救药箱里的冷藏胰岛素和止血内袋不见了……而且，地下设备区刚才传来了第一声惨叫。”

叶知衡压下手臂皮下的剧痛，缓缓抬起头，看向通往地下暗道的黑洞。

沉降纪元的第一夜，大幕拉开。
