# 第 1 章 葬礼上没人说真话

雨下到第三个小时的时候，许砺终于明白，原来人死了以后，世界不会安静下来。

殡仪馆外面的雨棚被砸得噼啪响，黑伞挨着黑伞，像一片贴在地上的乌云。来的人很多，许砺一开始还数过，后来数不清了。他只记得每个人进门前都先抖伞，再低头看一眼手机，最后才想起来要露出难过的表情。

他穿着一身不合身的黑衣服。

袖口太长，盖住半个手背。领口太硬，磨得脖子发红。妈妈早上替他扣扣子的时候，手指抖了三次，最后一次扣错了位，又拆开重来。她说：“小砺，今天别乱跑。”

许砺点头。

他没有乱跑。他只是站在灵堂门口，看着白花中间那张照片。

照片里的许怀川穿着灰色西装，笑得很浅，像每次出门谈工程前那样，摸一下许砺的头，说：“回来给你带模型船。”

模型船没有回来。

回来的是一只密封袋，里面装着父亲的手表、钥匙、一枚被磨花的婚戒，还有半张被雨水泡皱的停车票。

许砺盯着照片看了很久，久到眼睛发酸。他总觉得爸爸只是被这间屋子困住了，只要他一直看、一直看，照片里的人就会眨一下眼，皱着眉说：“臭小子，哭什么？”

可是照片没有动。

动的是旁边那些大人。

二叔许怀明站在休息室门口，小声接电话：“对，人走了。公司那边还没给说法……债务先别急着认，嫂子不懂这些，等我过去。”

许砺听见“债务”两个字，扭头看过去。

二叔立刻把声音压低，朝他挤出一个笑：“小砺，去陪你弟弟。”

许燃坐在角落的小板凳上，手里抱着一辆掉了轮子的玩具车。五岁的小孩还不太明白死亡，只知道今天不能大声说话，不能问爸爸去哪了。他鼻尖红红的，偶尔咳一下，就赶紧用袖子捂住嘴。

许砺走过去，把自己的水杯递给他。

许燃小声问：“哥哥，爸爸什么时候睡醒？”

许砺喉咙像被什么东西堵住。

他想说爸爸不是睡着。他也想说爸爸会醒。最后他只是把水杯塞进弟弟手里，说：“喝水。”

许燃乖乖喝了一口，又抬头看他：“妈妈是不是也病了？”

许砺看向灵堂另一边。

苏敏站在几个穿深色夹克的男人面前。她今天没有化妆，脸色白得像墙上的纸花，但背挺得很直。那几个男人不是亲戚，许砺没见过。他们胸口没有白花，鞋底沾着泥，像是从很远的地方赶来，又像是根本不在乎脚下踩进来的是什么地方。

其中一个男人拿着文件袋，说：“苏女士，我们理解你的心情。但许工生前签过项目责任确认，管廊三标段那边现在出了问题，后续赔偿和工程款冻结都要走流程。”

苏敏声音很低：“我丈夫是死者。你们今天在他的葬礼上，跟我谈赔偿和冻结？”

男人露出为难的表情：“不是我们不近人情，是债权方已经到了。公司也有公司的难处。”

“事故报告呢？”苏敏问，“交警那边说还要复核，你们怎么先把责任确认拿来了？”

男人没有立刻回答。

许砺看见他把文件往回收了一下，像怕苏敏看清楚。

另一个年纪大些的男人接过话：“许工是项目负责人，有些现场调度确实是他个人决定。嫂子，人已经走了，我们都难受，但活人还要过日子。你把字签了，公司尽量帮你争取抚恤。”

尽量。

许砺不知道为什么，突然很讨厌这个词。

以前爸爸也会说尽量。尽量早点回来，尽量带他去海边，尽量赶上家长会。爸爸说尽量的时候，会弯腰看着他的眼睛，像真的把这件事放在心上。

这些人说尽量的时候，眼睛只看文件。

苏敏没有接笔。

“我要看完整报告。”她说。

男人叹了口气：“苏女士，你这样拖下去，对孩子也不好。江湾那套房子还在按揭吧？银行那边……”

“出去。”苏敏说。

那男人愣了一下。

苏敏抬起头，眼睛红着，却没有掉泪：“今天是我丈夫的葬礼。你们要谈钱，要谈责任，要谈房子，明天拿着盖章文件来。现在，出去。”

灵堂里有一瞬间安静。

安静之后，又有窃窃私语钻出来。

“苏敏还是这个脾气。”

“她懂什么工程，公司愿意给钱就不错了。”

“两个孩子呢，以后怎么办？”

“江湾那房子肯定保不住。”

许砺站在原地，忽然觉得那些声音比雨还密，扎得人皮肤疼。

他想冲过去，把那些人全推开。可他才十岁，个子只到那几个男人胸口。他的拳头攥紧了，又松开，松开了又攥紧。指甲陷进掌心，疼得很清楚。

爸爸以前说过，男子汉不是谁声音大谁有理。

可现在声音小的人，似乎也没有理。

公司那几个人最后还是走了，走之前把文件袋放在休息室桌上。二叔追出去送他们，隔着雨帘点头哈腰，不知道说了什么。

许砺趁没人注意，走到桌边。

文件袋没有封死，里面露出一叠复印件。他认字不算慢，扫到几行黑字：南江港区跨海管廊，三标段，临时调度，责任确认。

最下面一页的页码是 7。

上一张却是 4。

他皱起眉，把纸往外抽了一点。

“小砺。”

苏敏的声音从身后传来。

许砺手一抖，纸边划过指腹，留下一道细细的口子。

苏敏走过来，把文件袋合上。她看见他手上的血，脸色变了一下，却先把文件压在掌下，像那里面藏着会咬人的东西。

“别碰这个。”她说。

“为什么少了几页？”许砺问。

苏敏沉默。

“爸爸是不是被他们冤枉了？”

苏敏抬手，想摸他的头。手伸到一半，又停住。她今天摸过太多冷冰冰的东西，香炉、骨灰盒、签字笔、别人递来的名片，好像连掌心都凉了。

“这些事，”她说，“妈妈会处理。”

许砺看着她：“你处理得了吗？”

话出口，他就后悔了。

苏敏眼底像被针扎了一下。

许砺低下头，嘴唇抿得发白。他想说对不起，可旁边又有亲戚过来，说火化时间快到了，让苏敏过去确认。

妈妈转身前，只来得及把他的手指握了一下。

那一下很轻。

轻得像她也快握不住什么了。

下午，雨更大。

遗体告别的时候，许燃终于哭出了声。小孩哭起来没轻没重，嗓子都哑了，喊爸爸不要睡。苏敏抱着他，肩膀抖得厉害，却没有让自己倒下。

许砺没有哭。

他站在最前面，看着白布下面那张熟悉又陌生的脸。爸爸额角有一块青紫，化妆也盖不住。许砺记得爸爸最怕他和许燃磕到碰到，每次都会蹲下来吹一吹，说吹吹就不疼了。

可现在没有人给爸爸吹。

火化炉门合上的那一刻，许砺听见身后有人叹气。

“可惜是可惜，就是许怀川这人太轴。”

“港区那项目水深，他非要查到底。”

“嘘，小声点。”

“怕什么？人都没了。”

许砺猛地回头。

说话的是两个陌生男人，一个瘦高，一个戴着黑色鸭舌帽。他们站在走廊尽头，没有戴白花，也没有看遗像。瘦高男人嘴里叼着没点燃的烟，察觉许砺看过来，还冲他笑了一下。

那笑不像难过，像看见路边一只冲人龇牙的小狗。

许砺朝他们走过去。

“你们认识我爸？”他问。

鸭舌帽男人低头看他，眼神扫过他的黑衣服和红眼眶：“小孩，回去找你妈。”

“你刚才说他查什么？”

瘦高男人把烟从嘴里拿下来，轻轻啧了一声：“耳朵还挺尖。”

许砺挡在他们面前：“你说清楚。”

两个男人对视一眼，像听见了什么笑话。

鸭舌帽弯下腰，声音压得很低：“想知道啊？那你长大点再问。现在问了也没用。”

许砺没有退。

他不知道自己哪里来的胆子。也许是因为爸爸已经被推进了那扇门，也许是因为妈妈今天低了太多次头，也许只是因为这两个男人脸上没有一点难过。

“我爸不是坏人。”他说。

瘦高男人脸上的笑淡了。

“坏不坏，不是你说了算。”他把烟别到耳后，直起身，“你爸要是早点懂这个道理，也不会死得这么难看。”

许砺脑子里嗡的一声。

走廊里的雨声、哭声、脚步声，全像被什么东西隔远了。

他只听见自己问：“你说什么？”

鸭舌帽拉了瘦高男人一把：“走了。”

瘦高男人转身前，最后看了许砺一眼。

“小孩，记住了。这个世上，不是谁委屈谁有理。你爸死得不冤。”

他们撑开伞，走进雨里。

许砺追了两步，被殡仪馆门口的人流挡住。黑伞一把接一把打开，他分不清哪一把下面是刚才那两个人。

他站在雨棚边缘，雨水被风卷进来，打湿了他的脸。

有人以为他终于哭了。

只有许砺自己知道，不是。

他没有哭。

他只是第一次觉得，手里要是有点什么就好了。

石头也行，棍子也行，随便什么都行。

至少能砸过去，让那两个人停下来，把话说清楚。

身后，苏敏在叫他的名字。

许砺没有马上回头。

他望着雨幕尽头，望着那两道消失的黑影，慢慢攥紧拳头。指腹刚才被纸划破的地方又渗出血，黏在掌心里，热得发烫。

那一天，他记住了三件事。

第一，爸爸不会再回来。

第二，大人可以在葬礼上说谎。

第三，如果你太小、太弱、太没用，连追上去问一句真话的资格都没有。
